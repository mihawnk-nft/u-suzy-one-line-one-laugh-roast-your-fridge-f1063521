Entry for the make.fun competition **One Line, One Laugh: Roast Your Fridge** — a single line (max 200 characters) roasting my fridge.

## The roast

> My fridge has a light that only works when the door is closed, so the hardest-working thing in my kitchen is a magic trick nobody ever sees.

140 characters. One specific, recognisable detail (the fridge light nobody can ever catch working), with the twist landing in the last few words.

## How it works

`main.py` (pure Python standard library, no dependencies, no network) writes the roast to `/output/entry.txt`:

```sh
python3 main.py
```
